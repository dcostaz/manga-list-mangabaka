# Nothing lost — MangaBaka, 3.x wrapper → contract 4.0.0

`Plan-2026Q4-tracker-plugin-standardization.md` Phase 4.1. Every public method of the 3.x wrapper
(`api-wrapper-mangabaka.cjs` at the tag `contract-3-final`) has exactly one row, classified **contract** (a §2
method the SDK's facade now generates, its source call in the client and its translation in the mapping),
**to client**, **to mapping**, or **deleted** (with the host call site that stops needing it). `npm run
check:nothing-lost` checks the table against the tag.

| Method | Classification | Where it went / why |
|---|---|---|
| `constructor` | deleted | The SDK builds the instance; nothing per plugin. |
| `init` | contract | `WrapperClass.init({ context, apiSettings, serviceSettings })`, generated by the SDK (contract §1.4). |
| `serviceName` | deleted | Static name; the SDK's `WrapperClass.pluginName` is the one name. Host fallbacks reading it (`coversearchorchestrator.cjs:869`, `trackersearchdelegate.cjs:424`) leave with Phase 5a's routing. |
| `pluginName` | contract | `WrapperClass.pluginName` and the descriptor's `pluginName`, from the manifest. |
| `pluginType` | deleted | The manifest's `pluginType` is the one source; the host reads the descriptor. |
| `capabilities` | deleted | The manifest's `capabilities` is the one source (the SDK refuses a mismatch at require time). |
| `credentialSchema` | deleted | A12: the manifest's `credentialOptions.fields` (`api_key`, the same key, so stored credentials keep working). Host reads at `apipluginhandler.cjs:216`, `:3504`, `pluginservice.cjs:681` move to the descriptor in Phase 5a. |
| `contractVersion` | deleted | The manifest's `pluginContractVersion`, checked against the SDK at build and at load. |
| `initialize` | contract | Generated; returns `{ status: 'ok' }`. |
| `getStatus` | contract | Generated; a Promise, no HTTP call (was synchronous). |
| `getCredentials` | deleted | No credential is held (A5); nothing to get. |
| `setCredentials` | deleted | A5: the credential arrives in each call's `callContext`. The host's hydration sites go in Phase 5a/5b. |
| `refreshCredentials` | deleted | Decision 4 / A5: a static token has nothing to refresh; a 401 is the SDK's one re-exchange and replay. |
| `testCredentials` | contract | A9; the client's `testCredentials` asks `/my/profile` with the token under test, on an identity of its own. |
| `search` | contract | Client `search` (the `/series/search` call, the per-scope search cache, `refresh`), mapping `search` (confidence 0–1, alt titles, `canonicalUrl`, `cached`/`fetchedAt`). `forceRefresh` is gone: §2.4's option is `refresh`. |
| `lookup` | contract | Client `lookup` (series detail), mapping `lookup` (the contribution plus `canonicalUrl`). A series MangaBaka does not have is `not_found` (was `null`). |
| `getSeriesUrl` | to mapping | A10: `canonicalUrl` on candidates and detail, from MangaBaka's own `canonical_url`. Host caller `trackersearchdelegate.cjs:646` stops needing it in Phase 5a. |
| `buildLinkContribution` | deleted | A8: the link path is `search.query` → the Reference → `enrich`. Host callers `apipluginhandler.cjs:2203`, `plugincapabilitydelegate.cjs:83` go in Phase 5a. |
| `syncEnrichment` | deleted | No host caller (analysis F13). |
| `enrich` | contract | Client `enrich` per entry (series detail), mapping `enrich` (`{ contribution }`); the SDK does the per-entry array. |
| `searchCovers` | contract | A7: `(query: { title }, options: { pluginEntryId })`; client finds the series (by id, or the top search result), mapping gives MangaBaka's one cover. The 3.x `trackerId`/`searchTitles` options are gone. |
| `downloadCover` | contract | Client: the cover bytes, cached per scope; the `<id>/<file>` form is still accepted. |
| `pullProgress` | contract | A1: one argument; client reads the library entry (404 → null), mapping gives `PluginPullResult` with MangaBaka's token. |
| `pushProgress` | contract | Client PATCHes `progress_chapter`/`progress_volume`/`rating ×10`, never a state; mapping reports what landed (`applied`). |
| `getReadingList` | contract | Client walks every page of `/my/library` (F17: the 3.x read one page, 12 entries at most); mapping keeps MangaBaka's token (A6). No library cache, no `comparison` (A13). |
| `compareProgress` | deleted | A13: the host compares; its output had no consumer (analysis F13). |
| `subscribe` | contract | Client PATCHes the state, POST on a 404 (live-confirmed 2026-08-26/27); the token arrives resolved by the host (A6). |
| `unsubscribe` | contract | Client DELETEs; a 404 is success (idempotent, §2). |
| `queryLive` | contract | Client series detail (404 → the `not_found` arm), mapping the `ok` arm without `linkState` (A4). |
| `summarizeEntries` | contract | Decision 3 / A4: the series' volatile state (publication status, chapter count) from series detail; no longer answered from the user's library, no `linkState`. |
